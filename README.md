web app solo project: Scholar Map - A platform to help students find local opportunities such as internships, competitions, part-time jobs, workshops and volunteering opportunities all in one place that will aid in their extracurriculars and career goals. 

Some features - Students can register to view opportunities and apply to them. They can see the list of opportunities they applied to and the ones were they got accepted.
Institutions can register and post opportunities for students, they can view the necessary documents and approve them for acceptance.

Tech stack - HTML, CSS , MySql, PHP
